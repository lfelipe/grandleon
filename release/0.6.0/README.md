# Grandleon 0.6

Grandleon is a creator and player for tactical RPGs. This release brings the
creator and player to Windows and Android, makes a first campaign easier to
build, and adds LAN co-op and downloadable campaigns on PC and Android.

## What’s new

- Start with named heroes, build and test your first battle, then expand into
  a campaign. Edit 1P and 2P formations in separate map tabs.
- Equip heroes with personal packs. Authors can define loot, set up shops
  before battles, tune progression and add optional story routes.
- Play **Steel and Cedar** alone or in local co-op. The demo includes hidden
  finds, optional battles and a castle whose rooms open as you explore.
- Host a LAN game on Android or PC and join with a second device. The host
  keeps the save, so both players can resume the campaign.
- Use **Browse Campaigns** to install and update games. Downloaded games also
  work offline.

## Run the downloads

| Download | How to start |
| --- | --- |
| Linux x86-64 | Extract and run `launch-pc.sh`. |
| Windows x64 | Extract and run `launch-pc.cmd`. |
| Android preview | Install the APK on a 64-bit Android 7 or newer device with OpenGL ES 3.0. |
| Console games | Open the N64 `.z64` or keep the PlayStation `.bin` and `.cue` together and open the `.cue`. |
| Optional console builders | Install the target’s builder beside the desktop launcher. |

The PlayStation disc has no Sony licence sector and needs a compatible
emulator or hardware setup. Both consoles target 30 FPS. Large PlayStation
castle maps can still scroll below that target. The Android APK is a
development-signed preview.
